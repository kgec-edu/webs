Quick Start: Use in ANY Website or GitHub Pages

Drop these two lines into the <head> of any HTML file or GitHub Pages template:

<!-- 1. Include webs CSS Framework --> <link rel="stylesheet" href="https://cdn.kgec.edu.in/webs/dist/webs.min.css" /> <!-- 2. Include webs Custom Elements Runtime (Optional) --> <script type="module" src="https://cdn.kgec.edu.in/webs/dist/webs.js"></script>
