1. Free GitHub CDN (jsDelivr & Statically)

Directly embed the design system from GitHub into any static HTML, Markdown, or GitHub Pages site with global Cloudflare edge caching:

Option A: jsDelivr GitHub CDN

<!-- 1. Universal webs CSS Framework --> <link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/kgec-edu/webs@main/dist/webs.min.css" /> <!-- 2. Web Components Runtime --> <script type="module" src="https://cdn.jsdelivr.net/gh/kgec-edu/webs@main/dist/webs.js"></script>

Option B: Statically GitHub CDN

<link rel="stylesheet" href="https://cdn.statically.io/gh/kgec-edu/webs/main/dist/webs.min.css" /> <script type="module" src="https://cdn.statically.io/gh/kgec-edu/webs/main/dist/webs.js"></script>
Zero Config

No Node.js Required

Drop two lines of HTML into any index.html and you have the complete KGEC styling and theme tokens.

Global Edge

Automated Updates

Every commit to main on kgec-edu/webs updates the CDN bundle automatically.

Universal

GitHub Pages Native

Perfect for club websites hosted on *.github.io with seamless HTTPS support.
