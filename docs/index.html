1. Quick Start: Use in ANY Website or GitHub Pages

Include the production CDN bundle directly inside your HTML <head>:

<!-- 1. Universal webs CSS Framework (Zero Dependencies) --> <link rel="stylesheet" href="https://website.kgec.edu.in/webs/dist/webs.min.css" /> <!-- 2. Web Components Runtime (Custom Elements) --> <script type="module" src="https://website.kgec.edu.in/webs/dist/webs.js"></script>
Vanilla HTML / Jekyll

GitHub Pages Ready

Works in static HTML, Jekyll, Markdown, and Hugo with pure CSS utility and component classes.

Custom Elements

Web Components

Declarative tags like <webs-navbar>, <webs-logo>, and <webs-footer>.

TypeScript Packages

5. React & Next.js Usage

Import components natively into any React or Next.js application:

import { WebsProvider, WebsNavbar, WebsLogo, WebsFooter, WebsButton } from '@kgec-edu/webs'; export default function App() { return ( <WebsProvider defaultTheme="theme-1"> <WebsNavbar /> <main> <WebsLogo variant="kgec" size={96} /> <WebsButton variant="accent">Apply Now</WebsButton> </main> <WebsFooter /> </WebsProvider> ); }
